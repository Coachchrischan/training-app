## Shipped and verified today

**Platform** (`Training-App/`, web 8128 + API 8129, Launchpad tile "Training App"):

- **Backend**: Express + `node:sqlite` (zero native deps), email+password auth with roles,
  invite-code athlete registration, seeded with ~2,800 exercises from the TrainHeroic library
  cache, demo coach (Chris) + 3 demo athletes + a demo team + a programmed week.
- **Coach console**: dashboard (activity feed + "needs a nudge" triage), athlete roster +
  detail (working maxes with tested/auto badges, private notes, bodyweight trend, recent
  sessions), calendar (week view per athlete/team, sessions + health tasks, copy/publish/
  delete), **session builder with unlimited prescription columns** (reps, rep range, kg,
  %1RM with live per-athlete kg resolution, RPE, RIR, tempo, rest, time, distance, calories;
  block kinds standard/superset/circuit/AMRAP/EMOM), exercise library + custom exercises,
  check-in form builder (scale/text/choice/number), teams, analytics (compliance bars,
  weekly tonnage, e1RM trend, readiness trend), messaging, Workout Builder JSON import
  (fuzzy-matched, drafts).
- **Athlete PWA**: Today stack (sessions AND health tasks: weight check-in, water,
  supplements, habits, readiness, custom forms), block-by-block logging with per-set
  check-off, prefilled prescriptions, %1RM resolved to kg from the athlete's max, rest
  timer, finish summary (session RPE slider, duration, comment), history, PRs with the
  TrainHeroic working-max rule (auto until tested, then pinned), messages, installable
  manifest + service worker.
- **White-label**: three brand packs (Coach Chris Chan Linden = default; Antenna Reef
  placeholder palette; BlueZone from its design system), semantic tokens only, terminology
  per brand (BlueZone says "clients"/"clinician"), per-brand module flags (BlueZone hides
  leaderboards + %1RM; Antenna Reef shows leaderboards). Dev switcher in Settings or `?brand=`.

**Verified end-to-end in the browser**: coach login → calendar → builder showing 4

## Known limitations (deliberate v1 cuts)

- Local machine only; SQLite on disk; no hosted backend yet (decision below).
- Reordering is up/down buttons, not drag-and-drop yet (dnd-kit is installed, queued).
- No AMRAP/EMOM scoring UI yet (block kinds + time caps exist).
- No recurring-task rule engine (repeat presets: daily-for-a-week, weekly-for-4).
- No offline logging queue in the PWA (app shell caches; API calls need connectivity).
- Team calendars merge into the athlete view read-only; team leaderboard endpoint exists,
  no UI panel yet.
- Antenna Reef palette is a marked placeholder.
- Seed dates: first seed ran before a UTC/local fix; the demo week sits a day early
  (delete `server/data/app.db` to reseed cleanly).

## Post-review hardening (same day, after the roundtable)

Ten findings fixed and re-tested against the running API. Four were serious: session
deletion destroying logged results, un-ticked sets counting as performed work (phantom
PRs and tonnage), team calendars leaking teammates' private data, and messaging having no
authorisation at all. Also: exit-without-losing-your-log, builder autosave races, an e1RM
rep cap, the BlueZone 18px/48px accessibility floors, colour-alone nav states, and
hover-only calendar actions. See `REVIEW-2026-08-16.md` for evidence and verification.

Biggest open item from the review: no week-level copy, templates across athletes, or
multi-select. Three reviewers raised it independently.
